## 🔬 Research & Projects

### 1. VAK Learning Style Clustering

A research project comparing **K-Means and Fuzzy C-Means** to analyze Visual, Auditory, and Kinesthetic (VAK) learning style patterns among high school students in Padang.

**Focus:** Unsupervised Learning, Clustering Evaluation, and Educational Data Mining.

[View Repository →](https://github.com/kimithora/VAKSistem)

### 2. Emotion Analysis Using NRC Emotion Lexicon

A text analysis project examining and comparing emotional patterns in Arash Buana's *Logic Mess* and *Life Update* albums using the NRC Emotion Lexicon.

**Focus:** Natural Language Processing, Text Mining, and Emotion Analysis.

[View Repository →](https://github.com/kimithora/NLP-with-NRC)

### 3. Machine Learning & Web Applications

Exploring the integration of data processing, predictive modeling, and web application development using Python and Flask.

[View Repository →](https://github.com/kimithora/RegLog-with-FLASK)
